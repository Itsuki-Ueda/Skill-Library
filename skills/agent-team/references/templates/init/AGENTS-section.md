# Team Worker Rules

このリポジトリは /agent-team（オーケストレーター）の管理下で開発されることがある。

- 親セッションは、機能追加・不具合修正・リファクタリングとその継続作業の依頼を、着手前に agent-team スキルを読んでから進める（圧縮・再開の後も同じ）。タスク契約を受けたワーカーは対象外。

- タスク契約（T-xxx.md）を渡されたワーカーは、契約プロンプトで名指しされたスキル
  （`team-worker` / `team-code-reviewer` / `team-plan-reviewer` / `team-researcher`）を
  読み、その行動規範に従うこと。行動規範の正本はスキル側にあり、ここには複製しない。
- タスク契約を受けたワーカーは、契約の Allowed paths 外、`.agents/` 配下、`AGENTS.md`、`CLAUDE.md` を変更しない。
