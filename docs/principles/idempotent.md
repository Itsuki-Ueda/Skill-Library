# 何度流しても安全に

状態を変える処理は、何回流しても、前回が途中で止まっていても、同じ正しい状態に落ち着くように作る。

## なぜ

処理は、落ちる・再起動する・再試行されるのが普通の場所で動く。途中まで残った状態で次の結果が変わるなら、再起動のたびに調べ直しになる。

## やり方

- 前回が何をするつもりだったかではなく、今ある状態から手順を決める。今の状態を読み、目標と比べ、差分だけを適用する。こう書いた手順は、2回目には何もすることが無い。
- 処理が残すもの（ロック・一時ファイル・書きかけの記録・取りかけの仕事）は、次の回が「古い」と判定できるようにする。判定は、前回がどこで止まっても成り立つ証拠で行う。例: 一時パスに書いてから名前を変えて置く。作られた順番ではなく中身で比べる。

## 確かめる問い

1. 2回続けて流したらどうなるか。
2. 前回がどの地点で落ちていても、どうなるか。
3. 流し直すと同じ最終状態になるか。

どれかの答えが「残った状態による」なら、今の状態と目標を突き合わせる手順を足す。
