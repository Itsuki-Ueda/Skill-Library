# gpt-consult — 人間経由 GPT Pro 相談プロトコル

## 役割分担（この線を越えない）

- **エージェントの仕事は「人間がそのままChatGPTに投げられる相談パッケージを完成させること」まで**。
  送信は常に人間（GPT ProはCodex/CCから呼べない。人間がチャットにアップロードする）。
- GPT Proは**仕事用GitHubを見られない**（プライベートGitは可）。したがって判断に必要なコードは
  **抜粋コピーとして同梱する**のが本スキルの中核。リポジトリ全体は渡さない。

## 発動条件（自発提案の言語化）

次のいずれかに該当したら、勝手に作らず**「GPT Pro相談パッケージを作りましょうか」と人間に提案する**:

1. **試行の枯渇**: 同一問題への修正が2回以上失敗し、原因仮説が尽きた
   （エラー修正ルール「推測禁止」と接続——推測で3周目に入る代わりにここへ来る）。
2. **ラウンド上限到達**: /agent-team の fix_rounds（task/express/plan）超過で人間へ上げるとき、
   選択肢の一つとして提示する。
3. **拮抗する設計判断**: 複数案のトレードオフが拮抗し、失敗コストが高いのに決め手が不足。
4. **レビュアー間の矛盾**: レビュー指摘が矛盾し、自分の裏取りでも決着しない。
5. **人間の指示**: 「GPTに相談」等と言われた（この場合は提案を挟まず作成に入ってよい）。

## パッケージ作成手順

出力先: プロジェクト直下 `consult/C-<yyyymmdd>-<slug>/`
（/agent-team 敷設済みプロジェクトは `.agents/consult/C-<yyyymmdd>-<slug>/`）。

1. **CONSULT.md** を書く。規律:
   - **背景ゼロの読者向けに自己完結**（プロジェクト内輪の略語・タスクIDを説明なしで使わない）。
   - **事実と推測を分離**（観測したことと、まだ仮説であることを節を分けて書く）。
   - 構成: 目的 / 前提・制約 / 事実（観測・実測） / 試したことと結果 / 選択肢と各トレードオフ /
     **番号付きの質問**（回答形式まで指定する。例:「Q1: 案A/Bのどちらか＋理由」）。
   - 冒頭に人間がそのまま貼れる依頼文を1段落で置く
     （「添付のCONSULT.mdとcode/を読み、末尾の番号付き質問に回答形式どおり答えてください」）。
2. **code/** に関連ソースを抜粋コピーする。
   - 判断に必要なファイルだけを厳選。各ファイル冒頭にコメントで**元の絶対パス**を明記。
   - ファイルの一部で足りるなら抜粋にし、`（抜粋: L120-L240）` と記す。
3. **機密フィルタ（機械的に適用・確認は不要）**:
   - 除外対象: `.env*`・APIキー/トークン/パスワード・秘密鍵・認証情報・顧客/個人データ・
     本番接続文字列。同梱前に `grep -iE "(api[_-]?key|secret|token|password|BEGIN.*PRIVATE)"` で機械検査。
   - ヒットした行は `<REDACTED>` に置換し、CONSULT.md 末尾「除外したもの」節に列挙する
     （回答者が前提の欠落に気づけるように）。
4. **zip化**: `C-<...>.zip` を相談ディレクトリの隣に作る（人間はこれ1つをアップロードすればよい）。
5. 人間への案内: zipの絶対パスと「ChatGPTにアップロードし、CONSULT.md冒頭の依頼文を貼ってください」。

## 復路（回答の取り込み）

1. 人間がGPT Proの回答を貼る。
2. **鵜呑みにしない**。判断を左右する主張・具体的な数値・「存在しない/不要」系の断定は、
   自分のコードベースで裏取りしてから採用する（グローバルルール第1.5層と同じ規律）。
3. `DECISION.md` を相談ディレクトリに書く: 採用/棄却した提案とその根拠（裏取り結果）/
   最終的に選んだ方針。/agent-team 実行中ならミッションファイルにも決定を1行転記する。

## ライフサイクル掃除（段階削除・厳守）

中身の価値は時点で変わる。zipとcode/は決着後ただの複製ゴミ、CONSULT/DECISIONは軽量な判断記録。

| タイミング | 掃除 |
|---|---|
| 人間が「送った」と言った時点 | **zipを即削除**（役目は運搬だけ。容量最大の一時物） |
| DECISION.md 記録時点 | **code/ を削除**（リポジトリの複製にすぎず再生成可能） |
| 残す | CONSULT.md ＋ DECISION.md（数KB。同種の悩みの再発時に参照） |

- 相談ディレクトリ作成時、`.gitignore` に `consult/*/code/` と `consult/*.zip`
  （agent-team敷設時は `.agents/consult/` 配下の同パターン）を追加する。
  相談本文・決定はコミット可、コード複製とzipはコミット不可。
- **取り残し対策**: 返答待ちを挟むため掃除は忘れやすい。相談ディレクトリを見かけたら
  「DECISION.mdがあるのにzip/code/が残っていないか」を確認し、残っていれば掃除する。

## 禁則

- 人間の依頼なしにパッケージ内容を外部サービスへ送信しない（送信は常に人間）。
- 機密フィルタを「急いでいるから」で省略しない。
- GPT Proの回答を裏取りなしで実装に反映しない。
