# 前提を疑う

同じ前提に立った修正が2回続けて同じ確認で失敗したら、修正ではなく前提を疑う。

## なぜ

失敗した修正は、それが当てにした前提が間違っている証拠でもある。同じ前提で3回目を試すと、原因が無いと分かっている場所に手間をかけることになる。

## やり方

1. 前提を1文で書き出す。失敗した修正のどれもが当てにしていた1文。
2. 次の修正の前に、前提を確かめる。前提が間違っていたら結果が変わる観察を1つ選び、実際に見る。失敗の大きさだけでなく、どこで・どんなときに失敗するかの散らばり方も見る。確認は流し直せる形にする（道具を作る）。
3. 前提が崩れたら、原因は別の場所にある。失敗に共通していて、前提では説明できないものを探す。前提が正しかったら、「なぜ」をもう1段掘る（根本原因を直す）。前の修正は、原因ではなく結果を手当てしていたのかもしれない。
4. 条件を補う仕組みを足すより、条件そのものを取り除く。後始末をする仕組みは原因を残したまま、毎回の手間を増やす。

## 止まる条件

前提を書き出して確かめる前に、次の修正を始めない。確かめても進まなければ、書き出した前提と確かめた結果を添えて判断を仰ぐ。
