# 振り返りをイシューにする

対象は、まとめ役の表の「採用」のうち行き先がスキル（説明文の調整・新しいスキルを含む）の行と、「保留（仕組みで止めるもの）」の行。
初めて出た案は、開いている「候補」のイシュー1件にコメントで足すだけにする。「判断待ち」として人間に上げるのは、同じ案が2回目に出たときだけ。1回きりの指摘を判断に上げないため（INBOX と同じ考え方）。候補をミッションごとに分けると、後の振り返りが前の案を見つけられず、2回目にならない。
イシューは人間が読んで採否を決める材料なので、1行の要約で済ませない。まとめ役の「詳細」から、実際に起きたことを具体的に書く。

## 1. 前に出た案を読む

```bash
repo=$(head -n1 ~/.config/skill-library/reflection-repo)
gh issue list -R "$repo" --label 判断待ち --state open --json number,title,url
cand=$(gh issue list -R "$repo" --label 候補 --state open --json number --jq 'map(.number) | min')
gh issue view "$cand" -R "$repo" --comments
```

候補のイシューが無ければ、1件だけ作る（`gh issue create -R "$repo" --label reflection --label 候補 --title "候補: 1回目の改善案" --body "初めて出た改善案を、振り返りごとにコメントで足す。同じ案が2回目に出たら判断待ちに上げる。"`）。2件以上開いていたら、いちばん古いものを使う。

## 2. 案ごとに振り分ける

同じ変更で直せる案（同じスクリプトの直し、同じ節への書き足し）は、先に1件にまとめる。同じ案とは、同じ問題を同じ場所で直す案のこと。似ていても直す場所か直し方が違えば別の案。

| 前に出ていたか | すること |
| --- | --- |
| 「判断待ち」に同じ案がある | そのイシューにコメントを足す。先頭は「2回目」（3回目以降はその回数）にして、「何が起きたか」と「出どころ」だけを書く |
| 「候補」の表に同じ案がある | 3 の手順で「判断待ち」を立て、候補のイシューに `→ #{新しい番号}: {その案}` とコメントする |
| どちらにも無い | 4 の手順で候補に足す |

## 3. 判断待ちを立てる

```bash
gh issue create -R "$repo" --label reflection --label 判断待ち \
  --title "{スキル名}: {何をどう変えるかを1行で}" --body-file {本文のファイル}
```

ラベルが無いと失敗する。そのときは一度だけ作ってから出し直す。

```bash
gh label create reflection -R "$repo"; gh label create 判断待ち -R "$repo"; gh label create 候補 -R "$repo"
```

本文の先頭に「2回目」と書き、次の見出しをこの順で全部書く。「何が起きたか」には、候補の行にある前回の出来事も書く。

```markdown
## 何が起きたか
{「何をした→何が起きた」の形で、記録の中の実際の出来事}

## 放っておくと
{次の作業で何に困るか。どんな場面でまた起きるか}

## どう変えるか
{スキルに足す・書き換える文そのもの、または足す検査（作り・型・lint・CI・テストのどれで止めるか）}

## 入れる場所
{スキルのパスと節。仕組みで止めるならその種類}

## 出どころ
{リポジトリ名、ミッション番号（あれば）、日付}

## おすすめ
{反映する / しない / 保留} — {理由を1文}
```

- 書いた人はイシューの作成者として残るので、本文には書かない。
- 顧客名・案件名・秘密の値・業務コードの抜粋は書かない。必要なら「{業務リポジトリA}」のように抽象化する。

## 4. 初めての案を候補に足す

振り返り1回につき、候補のイシューにコメントを1つ足す。本文と同じ列の表で、1案1行にする（人間と後の振り返りが一覧で見比べられるように）。本文は書き換えない（同時に書く別のセッションの行を消さないため）。

```bash
gh issue comment "$cand" -R "$repo" --body-file {コメントのファイル}
```

```markdown
| スキル | 案 | 何が起きたか | 元 | 出どころ |
| --- | --- | --- | --- | --- |
| {スキル名と節} | {何をどう変えるかを1行で} | {何が起きたかを1文} | {関連するイシューの番号。無ければ -} | {リポジトリ名、ミッション番号（あれば）、日付} |
```

セルの中に `|` を書くときは `\|` にする。
